## AI Project 6.10 – Performing Sentiment Analysis

### Project Overview
This project uses ChatGPT to analyze a customer review of an Italian restaurant, identify positive and negative aspects of the dining experience, and recommend improvements to attract more customers.

### AI Tool Used
ChatGPT (OpenAI).

### Project Files
- [Prompt](prompt.md) – The instruction and restaurant review provided to ChatGPT.
- [AI-Generated Output](ai-output.md) – The sentiment analysis.
- [Answers to the Questions](answers.md) – Responses to the four assignment questions.

### Conclusion
The review expresses mixed sentiment, leaning slightly positive. The food is a strength, while service during busy periods, pricing, noise and waiting times offer opportunities for improvement. The analysis is based on a single review and does not necessarily represent all customers.
